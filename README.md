# Машинка на CSS

Учебная работа на HTML и CSS. Машинка шириной **200px** автоматически выезжает слева при загрузке страницы, затем останавливается за **50px** до правого края.

- Вся анимация реализована средствами CSS (`@keyframes`).
- Дорога, пейзаж, кузов, крыша и колеса нарисованы на CSS.
- JavaScript и сторонние изображения не используются.
- HTML: один `main`, один `div` и два `span`.

## Запуск

Откройте файл `index.html` в браузере.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Адрес сайта после активации: https://syrcr.github.io/css-car/
