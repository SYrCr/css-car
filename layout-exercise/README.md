# Практическая работа 2Р

Четыре самостоятельных адаптивных HTML/CSS-страницы, выполненных по образцам Nicepage. Проект не использует сам Nicepage и не копирует его готовый экспорт.

- **2Р1:** Responsive Solutions (приблизительная реконструкция: исходный предпросмотр не был доступен полностью)
- **2Р2:** Grid Repeater with Numbers
- **2Р3:** Creating Marketing Plan
- **2Р4:** Design and Development Process

Адаптация: 3 колонки на больших экранах, 2 на планшете и 1 на телефоне (у 2Р2 2 колонки переходят в 1).

Откройте файл index.html для выбранного варианта. Живая демо-страница после включения Pages: https://syrcr.github.io/css-car/layout-exercise/
