# 2Р1 — Responsive Solutions

Практическая работа по HTML и CSS с мобильной адаптацией.

Образец: https://nicepage.com/html-templates/preview/responsive-solutions-1096380

Возможности: адаптивная сетка карточек (3 колонки на компьютере, 2 на планшете, 1 на телефоне), меню, ссылки на разделы, CSS-оформление. JavaScript не требуется.

Весь код страницы находится в `index.html`. Для просмотра достаточно открыть этот файл в браузере.

После включения GitHub Pages демонстрация будет доступна по адресу: https://syrcr.github.io/css-car/layout-exercise/2p1/

Это самостоятельная учебная вёрстка по мотивам макета, а не готовый экспорт Nicepage.
